## 4. 実績と判定（会議と同じ）

- 実績は会議タブと同じ関数（`keyKpiStats` → `_meetApplyPl` → `meetingBudgetKpi`）。今月は前日まで、予算の KPI は前日までの予算で判定。
- 判定は会議と同じしきい値（`getMeetThreshold`・`_meetStatus`）。原価率・人件費率は低いほうがよい。
- 目標：リピート率は人が決めた目標だけ（会議と同じ・業態の初期値は使わない）。原価率・人件費率は決めた目標、無ければ予算の率。ドリンク・アップグレード・いくらは 月の目標 ← 店舗の上書き ← 業態の初期値。
- 総労働時間：人件費と同じ勤怠（`laborCoreForYm`）の時間の合計。仕組みのアカウント（Toast Generic Login・LaLa の Server Default・Order Only・Kiosk など、業務Bot と同じ決まり）は名前で外し、外した時間を出す。判定は計画以内＝達成・超え＝計画超。今月の計画は 月の計画 × 前日までの営業日 ÷ 月の営業日（定休・臨時休業は数えない）。勤怠の無い日があれば「暫定」。
- 総労働時間と Google は、売上の集計が無い月でも出す（勤怠・手入力から）。これからの月は実績を出さない（「これから」）。
- 状態：会計 PL で確定した月は「確定」、それ以外は「速報（前日まで）」「暫定」など。

## 5b. 仕組みのアカウントを Toast のアカウント ID で外す（4A・11/13 に足した）

- hyper-worker（v1130・本番のソースを読んだ）は勤怠を取り込むとき、人ごとに Toast のアカウント ID（`te.employeeReference.guid`）を `tip_labor.data[].guid` に保存している。アプリの取り込み（`syncTipLaborFromDB`・`fetchTipLabor`）はこれを捨てていた。
- アプリ：取り込んだ 1 件に `toastGuid` を足す（`tipLaborWithGuid`。ID が無い・`unknown` のときは足さない＝今までと同じ形）。同じ人に 2 つの打刻を足した件は `toastGuids`（両方）。Tip の時間・配分・人件費の計算は変えない。
- 総労働時間：名前が仕組みのアカウント（`toastSystemAccount`）か、名前が仕組みのアカウントだったことのある ID（`k2SysGuids`：この端末にあるその店の勤怠の 13 か月前まで）を持つ件を外す。Toast で名前が変わっても外れる。
- 試験：名前を変えた仕組みのアカウントが ID で外れる・その証拠（前の日）が無ければ名前だけでは外さない・人は外さない・取り込みが ID を残す・2 つを足した件は両方の ID・ID が無い行は前と同じ形（`tests/toast-alias.test.mjs` の v1110 との比べも通る）。わざと壊す 4 通りすべてで落ちる。
- 休憩：hyper-worker は打刻の出入り（`inDate`〜`outDate`）で時間を数え、Toast の休憩（`breaks`・無給）を引いていない。人件費・Tip も同じ。引くかは Moto さんの判断（Tip と人件費が変わる）。
- CHAZUKE：hyper-worker は丼のモディファイヤーの名前で数える（`aosa`＝分母だけ・`crab`・`today`・`udon`＝分母と分子）。CHAZUKE は数えていない。Toast の名前と、味噌汁の代わりか足すものかが分かってから hyper-worker を直す。

## 7. 残ること・限界

- 会議タブの KPI の行は「対象外」を見ない（会議は今までどおり出す）。
- 仕組みのアカウントは名前と Toast のアカウント ID で外す（5b）。ID は v1153 のアプリで取り込み直した日から残る（前の写しは名前だけ）。名前が仕組みのアカウントだったことのある ID を、この端末にあるその店の勤怠（13 か月前まで）から集める（端末の写しが古いと、名前を変えたアカウントに気づかないことがある）。
- アップグレード率の CHAZUKE は Toast の品名が分かってから（7A）。今は味噌汁を付けた数。
- Google は手入力（月の平均・件数）。v1154 で Places API（新）を Edge Function から読む（鍵はサーバーだけ・決めた店の place ID だけ）。Places API で取れるのは最近の口コミ 5 件までなので、その月の全部の平均にはならない見込み → v1154 の UI 案で相談。
- 空にした目標は、前の月の目標を止められない（前の月の値に戻る）。止めたいときは「使う」を外すか、値を入れる。
- 重点カードは本当の役割で決める（G4 は画面の上では AM と同じ扱いなので `curRealRole` で見る）。G4 が全店を見る設定でも、カードは自店だけ。
- 実機（iPhone）・本番のデータでは確かめていない。
