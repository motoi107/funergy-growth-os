## 3. 権限

- 会議・仕入れの roles は予実管理と同じ（前は予実管理を開ける人が開けた）。中身の絞り込み（見える店・編集できる人・サーバーの確かめ）は前と同じ関数（`budgetScopeStores`・`qbCanEdit`・`ipsStoresFor`・`invInCanEdit`）。
- 経理センター・経理レビューのタブの roles は ceo・gm・office（前も AM・SL には出ていなかった）。1 ページだけのタブは、そのページに直接行くので、ここで絞らないと AM・SL に出てしまう。
- 等級ごとの非表示（設定 › Grade別の非表示ページ）：予実管理を隠していた等級には、会議・仕入れも隠す（GM・CEO が設定を一度でも変えると、そのときの見え方を書き出して印 `_v1084` を付ける）。見える人は増えない。
- 経理レビューの件数のバッジは、上の段のタブに出す（前は食材管理の中の小タブ）。

## 4. 古い行き先（お気に入り・通知・保存した状態・画面のリンク）

`navResolvePage`（`go` と `renderPage` の最初）が寄せる：

- 予実管理のタブが 会議・仕入れ → それぞれのページ。経営分析 → 予実管理の日次進捗。ほかの知らない値も日次。
- ワークセンターの 管理統括・対応依頼 → 今日。
- 原価率(FC) → 仕入れ、日次食材差異 → 棚卸し、備品発注 → 発注、管理統括 → ワークセンター、対応依頼 → マイページ。その人のナビに無い・開けないなら、その人のホーム（ログインした直後のページ）。
- お気に入り：廃止した画面のものは出さない（記録は消さない・数にも入れない）。予実管理の中の会議・仕入れで登録したものは、新しいページとして開き、★もそのページで点く。
- 通知の `page`（備品発注 12 か所・経理センター・経理レビュー）は上の寄せ方で開く。
- このアプリは URL で画面を覚えない（ハッシュも `?page=` も無い）。最後に開いたページも保存しない（ログインのたびにホーム）。保存されて残るのは、お気に入りと通知と等級の非表示だけ。
- 番号で並びを覚えている所は無い（タブは ID で探す）。
