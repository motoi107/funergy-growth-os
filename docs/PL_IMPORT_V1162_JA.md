## 1. 原因（参照ファイルで確かめた）

前の読み取り（v910〜v1161）は、合計行をちょうどの文字で探していた（`'total for 1.payroll expenses'`・`'total for 2. operating expenses'`）。2026 年 10 月版の PL では科目番号が付き（`Total for 60000 1.Payroll expenses`・`Total for 70000 2. Operating Expenses`）、どのシートでも「合計行が見つかりません」になってシートごと飛ばしていた。新しい `LALA` のシートは店の表に無かった。結果は「取り込める行がありません」（取り込みが止まる）。

参照ファイルを v1161 の本物のコードで読むと 0 行・すべてのシートで同じ知らせ。v1162 の読み取りで読むと、全 8 シートのすべての月が取り込め、知らせ 0。

## 2. 読み取りの決まり

- **行（A 列）**：科目は番号・名前・親（見出しと `Total for …`）で決める。行の番号はセルの場所を出すときだけ。空行・説明の行（金額なし）は飛ばす。名前は全角・半角・空白・大文字小文字・ハイフンの前後の空白をそろえて比べる。見出しは「あとに同じ名前の `Total for` がある行」。入れ子の小計は木にして、葉（科目）だけを足す（小計を二重に足さない）。`Head Office Expenses` のような番号の無い科目も同じ。
- **区分**：Income・Cost of Goods Sold・Expenses・Other Income・Other Expenses。人件費は Expenses の中の Payroll のグループ（`60000 1.Payroll expenses` など）。`41200 Sales - State Tax（GET pass-on)` は名前に Sales があっても、置かれている親（販管費の中の GET のグループ）で決まる。値引き・返品は符号のまま。
- **列**：月の見出しの行（いちばん多く年月が並ぶ行）を探し、月ごとに `CURRENT`（`Amount` `Actual` `当月` `金額` も）の列を読む。`% of Income`・右端の `Total`（期間の累計）は読まない。見出しの下 1〜3 行の小見出しは文字のセルだけ見る（% の書式の数値の表示「67.2%」を小見出しと取り違えない＝参照ファイルで起きた）。`CURRENT` の小見出しが無ければ、% でない一番左の列。次の月の列が足されても、列がずれても、見出しで決まる。
- **検算**：主要な合計（売上・原価・経費・その他の収入／費用・人件費のグループ・販管費のグループ）と明細の合計、粗利益＝売上−原価、営業利益（Net Operating Income）＝粗利益−経費、営業外損益（Net Other Income）＝その他の収入−その他の費用、最終利益（Net Income）＝営業利益＋営業外損益。どれかが合わない・空・数式エラー・数字でない値なら、**その店・その月は取り込まない**（前に取り込んだ値はそのまま）。知らせにはシート・月・項目・セル（例 `Marujuu!T67`）・期待・実際・差・直し方を出す。販管費の中のさらに下の小計（GET など）だけが合わないときは、小計の値を 1 行で取り込み、知らせる（合計は合ったまま）。幅は 1 セント。
- **空の月**：明細も合計もすべて 0 か空の月（開店前・閉店後・まだ来ない月）は取り込まない（推移では欠測。実績 0 と分ける）。
- **暫定**：月の見出しの注記に「暫定」、またはファイル名・見出しより上の題に「暫定」（provisional・preliminary・draft も）があれば、そのブックの最後の月を暫定にする。確定版を取り込み直すと確定に変わる。
- **店**：シートの名前で（`LALA` を足した）。分からないシートは取り込まず知らせる。同じ月の列が 2 つあるシートは取り込まない。

## 3. 新しい科目・区分

- 科目の行は番号・名前・小計の名前・金額・元の行を持って保存する（`pl_actual[月][店].ln`）。
- 変動費・固定費などの区分（前からの `PL_EXPENSE_CLASS_DEFAULT` と画面で決めた `pl_expense_class`）は、番号を外し、空白・ハイフンをそろえた名前で引く。10 月版で名前が変わった 3 つ（`Taxes - General Excise`・`Taxes, Licenses & Fees`・`Freight / Delivery(Dont USE)`）は前の区分を引き継ぐ。
- 区分の分からない科目は今までどおり「その他（未分類）」として金額ごと残る（推移の画面の「要分類」と割り当ては v1163）。参照ファイルでは 3 つ（GET の上乗せ分・酒類の手数料・出張の交通宿泊）。

## 4. 保存

- 取り込めた店・月だけを保存する。同じ店・月は丸ごと置き換える（足し込まない＝同じブックを何度取り込んでも同じ）。取り込まない月は前の値のまま。
- `pl_actual`（この端末だけ）に今までの欄（ドル）に加え、セントの主要な数 `c`・科目の行 `ln`・元のセルの列 `at`・暫定 `prov`・ファイル名 `file`・取り込んだ時刻 `imp`。
- `pl_public`（同期）は今までどおり売上・原価・人件費だけ。暫定の月にだけ `prov: 1`（利益・セント・科目は入れない）。会議タブの印はその月を「確定」ではなく「暫定」と出す（確定版を取り込むと「確定」）。
- `_src`（取り込んだ日）は取り込めた月だけ。暫定の月は「（暫定）」。

## 4b. 会議タブ・中間レビュー・KPI 管理への反映

- 3 つとも共有の `pl_public`（売上・原価・人件費）を読む（`_meetPlKpi`・`_meetConfirmState`）。取り込めた月は今までどおり「確定」の扱い（数字を会計 PL に差し替え・中間レビューでは前月の判定が要る）。
- 暫定の月は、数字と判定の扱いは同じで、言葉だけ「暫定」：会議タブの印（黄色の「暫定」）・KPI 管理の「暫定（会計 PL）」・中間レビューの前月の帯・前月の欄・カード・提出の説明の「会計 PL（暫定）」（`mrPrevProv`）。
- 中間レビューの提出版（サーバー）の前月の状態は `final` のまま（サーバーの形は変えない）。暫定かどうかはいまの端末の取り込みで見るので、確定版を取り込んだあとに前の提出版を開くと「確定」と出る（数字は提出のときのまま）。
- Waikiki（F03・F03-G）は今までどおり「合算」。会計 PL に月の数字が無い（全部 0 か空）の月は「速報」のまま。
