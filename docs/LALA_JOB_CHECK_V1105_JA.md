# LaLa の G1 の Job確認（16:30 基準）：業務Bot（アプリ v1105・関数 ops-bot）

依頼：Moto さん 10/21 18:49 HST の添付の ②（LaLa（F06）の G1 は 16:30 より前は Prep、16:30:00 以降は Prep 以外の Job。丸めない。実際の Job の ID で判定。未知の Job は「Job要確認」。業務Bot の画面・集計・通知に出す・同じ通知を重ねない・直したら判定し直す・判定不能は分ける・自動で直さない・開始日を設定できる）。UI案60（Design・Moto さんの非公開の canvas）の回答（10/21）：3 A（G1-P は見ない）・4「10/16 以降」・5 A（補助の確認は OFF）・6 A（判定したときの区分を残す）・7 A（Toast の Job の一覧を GM・CEO が分ける）・8 A（名前が結べなければ判定不能）。入れる手順は `deploy/ops-bot-job-check-v1105/手順.md`。

## 1. 決まり（`bot/job-check.mjs`）

- 見る打刻：Toast の timeEntries（Job の区間 1 つ＝打刻 1 つ）。消した打刻・仕組み上のアカウント（`isBotSystemAccount`）は見ない。
- 時刻：営業日の 0 時（ハワイ時間・`businessDate`）から打刻の開始（`inDate`）までの秒。日をまたいだ 0:30 は 24:30。Toast の `+0000` も読む。
- 期待：開始が基準（初期 16:30）**より前**＝Prep、**ちょうど以降**＝営業用。秒まで比べる（16:29:59 は前、16:30:00 は以降）。
- 判定の順：Job が「対象外」→ 見ない／開始時刻が分からない → 判定不能／従業員マスターで名前を結べない（見つからない・同じ名前が 2 人以上）→ 判定不能／G2 以上・ほかのグレード → 見ない／G1-P → 設定で「見ない」（初期）・「通常 G1 と同じ」・「要設定」（判定不能）／Job が未分類・知らない ID → 判定不能（Job 要確認）／期待と違う → 指摘（`job_before`：16:30 前なのに Prep でない／`job_after`：16:30 以降なのに Prep）／補助の確認（初期 OFF）：16:30 前に Prep で始めて、基準を N 分より長く過ぎても Prep → 確認（`job_straddle`）。
- 通常 G1／G1-P：アプリの従業員マスターの肩書き・役職（`GRADE_TITLES`・`empGrade`。アプリと同じ表を試験が見張る）と Prep の印（`data.prep`）。判定したときの区分（`grade`・`grade_name`・`graded_at`）を案件に残し、あとで昇格・異動しても書き換えない。
- 案件：今の勤怠の案件（`labor:…`）とは別のキー `labor_job:<店>:<営業日>:<timeEntry>`（種類は勤怠）。指紋は打刻・Job・判定だけ（取得時刻・区分は入れない）＝同じ指摘は毎朝読み直しても開き直さない。
- 確かめ直し（`checkCase` → `checkJobCase`）：設定が OFF → 記録だけ／打刻が消えた → 解決／営業日・人が変わった → 人が見る／Job が直った・見なくてよくなった → 解決／まだ違う → そのまま。
- 朝の報告：勤怠の案件と同じ「勤怠管理｜Moto・Yuki」に、`LaLa／通常G1／15:00:12開始／Server → 16:30前のためPrepか確認` の 1 行。
- Bot は打刻・Job・時給・支給額を直さない。Toast の Job の一覧から時給（`defaultWage` など）は取り出さない。

## 2. 設定（`bot_settings` の `job_check`・GM・CEO）

- 店ごと：使う／基準の時刻／この日の勤怠から（LaLa は 2026-10-16 から）／G1-P の扱い／補助の確認／Job の ID ごとの区分（Prep・営業用・対象外・未分類）。店を足すときはここに店の決まりを足す（コードは変えない）。
- 保存は店ごとの版（`rev`）つき：開いたときの版と違えば保存しない（409）。行全体も版（`value.rev`）つきで書くので、ほかの店の同時の保存も消さない。版の無い前の設定は版 1。
- 関数の口：`job_list`（Toast の Job の一覧・ID は小文字・時給なし・今の設定と版）・`job_check`（保存・`expect_rev` が要る）。どちらも GM・CEO だけ。

## 3. 画面（アプリ v1105・業務Bot）

- 設定 →「Job確認（16:30 基準）」（GM・CEO）：店・使う・基準の時刻・開始日・Job の区分（Toast から読み直す）・だれを見るか・補助の確認。
- 案件：種類の絞り込みに「Job確認（16:30）」。一覧に「勤怠・Job確認」・判定不能の印。1 件の画面に打刻（営業日の 0 時から）・実際の Job → 期待・判定したときの区分・基準と開始日、判定不能は「違反ではない」。LINE の下書きは Job の文。今の勤怠の表示（抜き出して ops-bot と同じにしている範囲）は変えていない。
