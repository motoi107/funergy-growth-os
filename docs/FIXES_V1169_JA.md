## 2. Claude が決めたこと（Moto さんに伝える・違えば直す）

- 申請の段（`wr_stage`）は変えない（7 のまま）。申請/承認（v1165）の ③ が段 7 ちょうどを見るため。「処理済み（今月）」の新しい読み方は、関数が `wr_acct_done` の有無で見分ける。
- チャットの段は 5。前の版のチャットの SQL は段 5 の上では止まる。直しが要るときは、いまのリポジトリのファイルを順に（添付 → チャット改修 → 守り → v1169）。11/14 に渡した `まとめ_v1163-v1168.zip` の中のチャットの SQL には止める仕組みが無いので、もう使わない。
- 申請のチャットを新しく作り直したとき、前の会話は申請から外すだけで消さない（`ref_old`）。前の会話の中身は、前の参加者（いまはだれも読めない）にしか見えない。作り直す人には「この申請のチャットは前にありましたが、いま読める参加者がいません。新しく始めます（前の会話は、だれにも見えないままです）」と出す（日英）。
- 最後の参加者が抜けられないのは申請のチャットだけ（グループは前のまま。だれもいないグループは残らないので）。
- 「読める参加者」＝いまの参加者で、前の自動の参加者でなく、社員の表で在籍している人（`chat_emp_ok`）。
- 年間計画で読めなかった月は 60 秒ごと（描き直しのとき）に読み直す。描くたびには読まない（止まらない）。
