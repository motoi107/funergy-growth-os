## 1. できること

- ログイン画面：事業所 → 名前（GM・CEO・経理の名前に盾の印）→ **メールとパスワード**。管理者セキュアページと同じアカウント。
- 入ると、PIN のログインと同じ形の「ログインの印」（12 時間）を受け取る。ほかの関数（Toast・申請・チャット・給与など）はそのまま動く。
- 「PIN でログイン（試しのあいだ）」で今までどおり PIN の段。PIN の段の下の「メールとパスワードでログイン」で戻る。
- 「パスワードを忘れたとき」：GM・CEO に頼んで新しくしてもらう（アプリからは変えない・メールの送り手が無いため）。
- 新しい端末で入ると、本人（「新しい端末でログインしました」）とほかの GM・CEO（「〇〇さん（GM）が新しい端末でログインしました」）にアプリの知らせ。
- マイページに「メールとパスワードでログイン中」のカード：管理者セキュアページを開く（メールを入れ直さない・「アプリに戻る」で画面と役割が戻る）・PIN を入れる（給与を読むため・要るときだけ）・すべての端末からログアウト。
- GM・CEO はチャットで「操作がないとロック」をしない（「今すぐロック」とアプリを切り替えたときに隠すのは今までどおり）。ロックの画面と守りの画面にそう出す。

## 2. 守り

- **サーバー（device-login の email_login）**：Supabase Auth のメールのログイン（Bearer）で利用者を確かめ、SQL `dl_email_login` が manager_auth の行で決める。その行が**選んだ名前の社員と結ばれていて**（`emp_id`）、役割が ceo・gm・office、社員が在籍のときだけ入れる。アプリが送る名前・役割は使わない。
  - 返す理由：`forbidden`（役割が違う・アカウントが無い）・`not_linked`（社員と結ばれていない）・`wrong_person`（ほかの人の名前）・`inactive`（止めた・退職）。
  - SQL が無い（404）は `not_installed`（503）。アプリは「PIN でログイン」を案内する。
- **端末**：端末の番号（ランダムな UUID・`_ml_dev_v1`）だけを端末に残す。サーバーは「社員 ID ＋ 番号」の sha-256 だけ持つ（新しい端末の知らせのため）。**番号は鍵ではない**（入るには毎回メールとパスワードが要る）。
- **メモリだけ**：Supabase の鍵・ログインの印・メールはこのタブのメモリだけ。パスワードは送ったらすぐ欄から消す。開き直すとメールとパスワードをもう一度。
- **取り替え**：30 分ごと（と画面に戻ったとき）に Supabase の鍵（期限の 15 分前から）とログインの印を取り替える。そのとき止めた・退職・権限が変わった人はログアウト（理由を出す）。つながらない・サーバーの一時の失敗はそのまま（あとでもう一度）。
- **ログアウト**：メールのログインをサーバー側でも閉じる（この端末）。「すべての端末からログアウト」はサーバーの global。
- 表 `dl_email_devices`・関数 3 つ（`dl_email_login`・`dl_email_notice`・`dl_email_stage`）はサーバーの鍵だけ（RLS・公開の鍵では読めない・呼べない・security invoker）。記録は v1183 と同じ `dl_events`（パスワード・鍵・印は残さない）。
- 知らせは app_state の notifications に 2 つ足すだけ（行をロックして足す・配列でなければ足さない・ほかの知らせは消さない・500 件まで）。足せなくてもログインは止めない（記録に残す）。

## 3. 給与（emp-private）

- 今の本番の emp-private（v5）は PIN でしか確かめない。v1185 の 1 ファイル（非公開）は **ログインの印でも** 頼めるようにした（v5 との違いはそこだけ。PIN の道・役職・返す中身は v5 のまま）。
  - 印は HMAC で確かめ、印の社員 ID で社員の行を読む（名前・役職はアプリから送られたものを使わない）。退職・OS の無効は断る。書き換え・期限切れは 401。
- アプリ：PIN なしで入った人（メール・端末のログイン）は印で頼む。emp-private がまだ v5（印を断る）なら、入ったあとに **PIN を 1 回だけ** 聞く（キャンセルしても続けて聞かない・マイページの「PIN を入れる」から）。
- 給与を読めていないとき、メールで入った人の給与・連絡先の保存は送らない（今の給与が画面に出ていないので、空の値で上書きしないため）。

## 4. Claude が決めたこと（Moto さんに伝える・違えば直す）

- 端末の番号は「新しい端末」の知らせのためだけに置く（3 の「覚えない」と矛盾しない：ログインには使わない）。
- 権限が変わった・止めた・退職のとき、最長 30 分（か画面に戻ったとき）でログアウトする。
- 経理のログインも、ほかの GM・CEO に知らせる（経理同士には出さない）。
- PIN の段の下のボタン：GM・CEO・経理は「メールとパスワードでログイン」（メールの段へ）。ほかの人は前と同じ「メールで管理者ログイン（より安全）」（管理者セキュアページ）。
- 管理者セキュアページの「ログアウト」は、アプリから開いたときはアプリのログアウトと同じ（保存していない入力があれば聞く）。
- 試しのあいだ、PIN で入った GM・CEO・経理は今までどおり（メールのカードは出ない）。
