# 会議タブ：単一営業区分と客単価目標（1010）

対象：GitHub版 Funergy+。基準 main `2b3b9ea`。実装 Codex。

## 原因と修正

Toastの既存同期は注文の開始時刻とL/D境界で分類する。ランチ営業が無い日でも早い時刻の事前注文はランチになる。Tipは既に曜日別設定のランチOFFを見てディナーへ合算する一方、会議の売上・客数は未補正だった。

`salesActualForDay` は表示用コピーだけを補正する。既存の営業時間設定がランチOFF・ディナーONで、終日休／ディナー休でない日に、売上・客数・TO売上・TO件数のLをDへ合算する。全体売上・全体客数は不変。会議KPI、売上／客数／単価の詳細、人件費の売上分母に適用。共通KPI関数を使う画面も同じ分類になる。設定無し・昼夜営業・終日休は元の分類を維持する。

客単価目標は日別に調整した売上予算を未調整の客数予算で割っていたため、休業・祝日調整で入力単価からずれた。`budgetSpendBasis` は対象月の曜日回数と入力客数／注文件数で入力単価を加重平均する。店内はTOを除く。区分別予算にも対応。入力単価が無い場合は従来の計算へフォールバックする。売上予算の日別調整・客数予算は変更しない。

売上差の要因分解に出る「予算売上に必要な客単価」は従来どおり日別売上予算÷客数であり、入力した単価目標とは別の用途。固定済みの過去会議記録・手入力上書きは維持する。
