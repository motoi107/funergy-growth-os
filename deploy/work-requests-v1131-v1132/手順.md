# ワークセンターの申請を入れる手順（1 段目 v1131 と 2 段目 v1132 をまとめて）

使うファイルは 4 つ（Moto さんに直接渡したもの）：

| 番号 | ファイル | どこで |
|---|---|---|
| ① | `1_最初に確認_読むだけ.sql` | Supabase の SQL Editor |
| ② | `2_SQL_1段目と2段目.sql` | Supabase の SQL Editor |
| ③ | `3_確認_読むだけ.sql` | Supabase の SQL Editor |
| ④ | `work-requests_v1132_index.ts`（非公開・リポジトリには無い） | Supabase の Edge Functions |

## A. Supabase（4 つのファイル）

1. **SQL Editor に ① を貼って Run。**
   - 「STOP」が 1 つも無ければ次へ。STOP があれば止めて、結果の画面を Claude に。
   - 「mileage rate」が NG なら、先にアプリのガソリン代の画面の「設定」で単価を入れる。
2. **SQL Editor に ② を貼って Run。**
   - 「Success」なら次へ。エラーなら止めて、エラーの文を Claude に。
3. **SQL Editor に ③ を貼って Run。**
   - 「result」の列に NG が 1 つも無ければ次へ。
4. **Edge Functions で関数 `work-requests` を作る（もうあれば開く）→ ④ の中身を全部貼って Deploy。**
   - 設定の **Verify JWT は OFF**。
   - 新しく入れる秘密の設定は無い。

## B. GitHub（マージ）

5. **PR を #122 → #123 → #124 の順にマージ。**
   - 3 つとも「Merge pull request」を押すだけ。順番を変えない。

## C. アプリ

6. **G4・GM・CEO・経理・事務Crew の端末で、アプリの「更新」を押す。**ログイン画面の版が 1132 になれば OK。
7. **GM か CEO が、ワークセンター →「申請」→「使い始める」。**
   - 先に「承認・閲覧の権限の確かめ」が開く。一覧の AM と G4 以上の人を見て、合っている人に印を付けて確定する（この一覧に入った人だけが、AM として承認する・G4 として評価の変更を申請する）。
   - 前の画面にあったガソリン代・建て替え経費・事前経費の申請が写る。

## うまくいかないとき

- 「PIN のログインに対応していません」：4 で貼ったのが ④ ではない。④ を貼り直す。
- 「データベースが 1 段目（v1131）のままです」：2 をもう一度流す。
- 止めたいとき：`deploy/work-requests-v1131/止める.sql`（申請の記録は残る）。止める前に Claude に相談。
