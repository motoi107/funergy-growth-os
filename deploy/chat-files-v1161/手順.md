# チャットの添付（写真・PDF・Excel・Word など）を入れる手順（v1161：UI案75 の答え）

チャット（DM・グループ・申請のチャット）に、写真・PDF・Excel・Word・PowerPoint・テキストを付けられるようにします。
中身は Supabase の Storage の**非公開の置き場所 `chat-files`** に置きます（公開の鍵では読めない・書けない）。

使うファイル：

| 番号 | ファイル | どこで |
|---|---|---|
| ① | `1_最初に確認_読むだけ.sql` | Supabase の SQL Editor |
| ② | `2_SQL_添付.sql` | Supabase の SQL Editor |
| ③ | `3_確認_読むだけ.sql` | Supabase の SQL Editor |
| ④ | `work-requests_v1161_index.ts`（非公開・リポジトリには無い・Claude が直接渡す） | Supabase の Edge Functions |

## A. Supabase

1. **SQL Editor に ① を貼って Run。**「STOP」が 1 つも無ければ次へ。
   - 1 が STOP なら、先に `deploy/chat-v1156`（チャット）を入れる。
   - 3・4 が STOP なら止めて、出た名前を Claude に（Storage の決まりで、公開の鍵から添付が見えてしまうおそれ）。
   - 2 の行が 0 なら初めて、1 ならもう入っています（② をもう一度流しても同じ）。
2. **SQL Editor に ② を貼って Run。**「Success」なら次へ。
   - エラーなら止めて、エラーの文を Claude に。直してからもう一度 ② を流せば同じ結果になります。
   - Storage に置き場所 `chat-files`（非公開・1 つ 10MB まで・決まった形だけ）を作ります。
3. **SQL Editor に ③ を貼って Run。**「result」の列に NG が 1 つも無ければ次へ。
   - 5・6 が NG なら、②のあとにチャットの SQL（`deploy/chat-v1156` の ②）を流し直しています。この ② をもう一度流してから ③。
   - 7・8 が「—」なら Storage がありません（Supabase の本番にはあるはず。Claude に）。
4. **Edge Functions で `work-requests` を開いて、④ の中身を全部貼って Deploy（Verify JWT は OFF）。**
   - ④ は申請（段階 2・3）とチャットも今までどおり動かします（v1159 の中身に添付を足したもの）。
   - ④ を貼る前に ② を流しておく（逆でも壊れませんが、そのあいだ添付は「サーバー（SQL）がまだ」と出ます）。

## B. GitHub

5. **アプリ**：この PR（v1161）をマージ。順番は #151 → #152 → #153 → #154 → この PR。

## C. アプリ

6. **全員の端末で、アプリの「更新」を押す。**ログイン画面の版が 1161 以上になれば OK。
7. **使い方**：チャットの入力欄の左の 📎 で付ける → 送信（文は無くても送れる）。
   - 写真は送る前に端末で縮めます（長い辺 2000px の JPEG・一覧用の小さい写真も）。
   - 1 回に 5 つ・1 つ 10MB まで。種類は 写真・PDF・Excel（xlsx・xls・csv）・Word（docx・doc）・PowerPoint（pptx・ppt）・テキスト（txt）。
   - 会話の上の「ファイル」で、その会話のファイルの一覧（新しい順）。
   - 建て替え経費の申請のチャットでは、申請した本人が写真・PDF の「申請に付ける」で申請の領収書にできます（承認待ち・差し戻しのあいだ）。申請の画面の「領収書」から開けます。

## 決まり（Moto さんの答え 11/13「1 B 2 A 3 A 4 A 5 A 6 A 7 A 8 B」）

- **1B 種類**：写真・PDF・Excel・Word・PowerPoint・テキスト。名前だけ変えたもの（例：中身は ZIP なのに .pdf）はサーバーが断ります。
- **2A 写真**：送る前に縮める。
- **3A 数と大きさ**：1 回に 5 つ・1 つ 10MB まで。
- **4A 保存**：その会話を見られる人はだれでも開いて保存できる（開くたびに 5 分だけ使えるリンク）。あとから加わった人で「これまでの会話を見せない」にした人は、前のファイルを開けません。
- **5A 消す**：本人がメッセージを消すとファイルもサーバーから消えます（申請の領収書にしたものは申請の記録として残る）。GM・CEO が見えなくしたものは、ファイルも出さない（サーバーには残る・戻すとまた出る）。
- **6A 残す期間**：メッセージがある限り残す。付けたまま送らなかったファイルは 1 日で消えます。
- **7A 一覧**：「この会話のファイル」。
- **8B 申請に付ける**：建て替え経費の申請のチャットの写真・PDF を、申請した本人が申請の領収書にする。
- **この端末には残さない**：付けたファイルは送るまでこのタブの中だけ（ログアウトで消える）。
