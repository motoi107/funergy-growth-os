# チャットの添付を止めたいとき（v1161）

いちばん軽い止め方は **関数を前の版に戻すこと**です。送ったファイル・メッセージはサーバー（Storage の `chat-files` と表 `chat_files`）にそのまま残ります。

1. Edge Functions → `work-requests` に、前の非公開のファイル `work-requests_v1159_index.ts` を貼って Deploy（Verify JWT は OFF）。
2. アプリで付けて送ろうとすると「添付は、チャットのサーバー（関数 work-requests）が v1161 になってから使えます」と出ます。文字のチャット・申請は今までどおり動きます。
   - 前の関数は添付を開くリンクを出さないので、もう送ったファイルも開けなくなります（消えてはいません）。
3. また使うときは `work-requests_v1161_index.ts` を貼り直すだけ（SQL は流し直さなくてよい）。

**SQL（②）を戻す SQL は用意していません。**② のあとにチャットの SQL（`deploy/chat-v1156` の ②）を流すと、送る・消すが添付を知らない前の形に戻り、
付けたファイルが送れなくなります（③ の 5・6 が NG）。添付を使い続けるときは、その後に ② をもう一度流してください。

ファイルそのものを消す SQL も用意していません（消すと戻せないため）。消したいときは Claude に言ってください。
