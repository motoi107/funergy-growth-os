# v1121 業者マスター：入れる手順

1. Supabase の SQL Editor で `1_追加のSQL.sql` を流す（何度流しても同じ）。
   - 「public.vendors がありません」で止まったら、何も変えていません。Claude に知らせてください。
2. `2_確認のSQL_読むだけ.sql` を流す。次の 3 行が true ならよい：
   - guard function
   - guard trigger on vendors
   - browser roles cannot run the guard directly
   - 残りの行は数だけ（削除・無効・区分の数）。
3. アプリ（PR）をマージする（SQL を入れる前にマージしても動きます）。
4. 業者マスターを使う端末をすべて 1121 にする。
   - v1120 以前のアプリは削除・無効を知らないので、削除した業者がその端末の一覧に出ます。
   - SQL を入れていれば、その端末が保存しても削除・無効・区分は戻りません。
5. 業者マスターを開くと、工事関係業者のカードが入ります（1 回だけ）。「工事関係業者」の絞り込みで確かめてください。
6. 重複は「業者の統合」でまとめる（Moto さん）。使われていない業者は「削除・無効…」から削除できます。
   - 削除・無効は経理・事務Crew・GM・CEO だけ。削除にはメール認証が要ります。

止めるとき：`止める.sql`（見張りを外すだけ。データは変えない）。アプリを前の版に戻しても、削除した業者はクラウドに印が残ったままです（前の版では一覧に出ます）。
