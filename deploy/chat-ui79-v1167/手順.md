# チャット改修（UI案79）を入れる手順（v1167）

読めるのは**参加者だけ**にします（GM・CEO・経理・店長も、参加していない会話は見えません）。申請のチャットは、最初に開いた人が参加者を選んで作ります（関係する人が最初から選んであり、外せます）。
PC はどの画面でも右下の「チャット」から開くパネル（動かす・大きさを変える・前面に固定・別ウィンドウ）、スマホは下から半分の画面。スクショを貼って丸・矢印・説明を付けて送れます。「今すぐロック」と、操作がないときのロック（店の共有 PC 5 分・自分の端末 30 分）。

使うファイル：

| 番号 | ファイル | どこで |
|---|---|---|
| ① | `1_最初に確認_読むだけ.sql` | Supabase の SQL Editor |
| ② | `2_SQL_チャット改修.sql` | Supabase の SQL Editor |
| ③ | `3_確認_読むだけ.sql` | Supabase の SQL Editor |
| ④ | `work-requests_v1167_index.ts`（非公開・リポジトリには無い・Claude が直接渡す） | Supabase の Edge Functions |

先に入っていること：チャット（`deploy/chat-v1156`）・添付（`deploy/chat-files-v1161`）。申請/承認（v1165・#161）の関数 ④ を入れていれば、この ④ はその中身にチャット改修を足したもの（申請・承認・添付は今までどおり）。

## A. Supabase

1. **SQL Editor に ① を貼って Run。**「STOP」が 1 つも無ければ次へ。
   - 1 が STOP なら、先に `deploy/chat-v1156` → `deploy/chat-files-v1161` を入れる。2 が STOP なら申請の段階 2（`deploy/work-requests-v1155`）。
   - 3 の行が 0 なら初めて、1 ならもう入っています（② をもう一度流しても同じ）。
   - （参考）の数は表をとっておく（Claude との会話にだけ貼る。会話の中身・名前は出ません）。
2. **SQL Editor に ② を貼って Run。**「Success」なら次へ。
   - 「STOP: 先にチャット…」と出たら何も変わっていません。1 の案内のとおりに。
   - そのほかのエラーなら止めて、エラーの文を Claude に。直してからもう一度 ② を流せば同じ結果になります。
   - 前からある申請のチャットで**自動で入っていた人**は、**いまその申請を見られる人だけ残し、ほかは外します**（今より多く読める人は出ません）。グループ・申請のチャットには管理する人が 1 人ずつ決まります（作った人。いなければいちばん前から入っている人）。
3. **SQL Editor に ③ を貼って Run。**「result」の列に NG が 1 つも無ければ次へ。
   - 1・3・4 が NG なら、② のあとにチャットの SQL（`deploy/chat-v1156` の ②）を流し直しています（読める人が前の決まりに戻ります）。→ 添付の ②（`deploy/chat-files-v1161`）→ この ② の順にもう一度。v1169 から、いまのリポジトリのチャットの SQL は、新しい段の上では止まります（「STOP: これより新しいチャットの SQL…」・何も変えない）。それでも NG になったら、v1169 より前に渡したファイル（`まとめ_v1163-v1168.zip` など）を流した可能性があります。
   - 12 が NG なら、申請の SQL を流し直しています。申請の段階 2 → チャット → 添付 → この ② の順に。
4. **Edge Functions で `work-requests` を開いて、④ の中身を全部貼って Deploy（Verify JWT は OFF）。**
   - ② の前に ④ を貼っても壊れません（そのあいだ「申請のチャットを始める」「管理する人」は「サーバー（SQL）がまだ」と出ます）。
   - ② のあと、④ がまだ前の版（v1165 など）だと、申請のチャットを新しく作れません（「関数が v1167 になってから」と出ます）。DM・グループ・前からある会話は動きます。

## C. アプリ

6. **全員の端末で、アプリの「更新」を押す。**ログイン画面の版が 1167 になれば OK。
   - 1166 以前の端末でも DM・グループ・前からある会話は読めます。新しい申請のチャットは始められません（「この申請のチャットには入っていません」と出ます）。
7. **確かめ（本番・Moto さん）**：
   - PC：年間計画などの画面で右下の「チャット」→ パネルが画面の上に出る（下の画面はそのまま）・上の帯を持って動かす・右下の角で大きさ・ピンのボタンで「アプリの中で前面」・「別ウィンドウ」（Chrome・Edge は「いつも前面」＝ほかのアプリの上にも出る）・別ウィンドウの「元の画面に戻す」。
   - PC：画面のスクショを ⌘V／Ctrl＋V → 丸・矢印・元に戻す・説明 →「送る」で 1 件。
   - iPhone：ホーム画面のアプリで、チャットが下から半分・「広げる」で全画面・写真を押すと全画面でピンチ・ダブルタップで拡大。
   - 申請の画面の「この申請のチャット」→ 関係する人が選んである → 外す・足す → 始める。参加していない GM・CEO には「参加者だけが開けます」。
   - 🔒「今すぐロック」→ 店の共有 PC はログインの PIN で続ける。

## 決まり（Moto さんの答え 11/14 09:29 HST「1〜6 A」）
