# チャット改修（v1167）を止めたいとき

**SQL（②）を戻す SQL は用意していません。**② を戻すと「申請を見られる人は申請のチャットを読める」前の決まりに戻り、読める人が増えるためです。

## アプリだけ戻す

- アプリを 1166 に戻しても、DM・グループ・前からある会話は読めて送れます（読めるのは参加者だけのまま）。
- 1166 のアプリでは、新しい申請のチャットを始められません（「この申請のチャットには入っていません」と出ます）。右下のボタン・パネル・別ウィンドウ・画像の印・ロックは無くなります（v1161 の画面）。

## 関数だけ戻す

- Edge Functions → `work-requests` に前の非公開のファイル（`work-requests_v1165_index.ts`、#161 のもの）を貼って Deploy（Verify JWT は OFF）。
- 申請・承認・添付・DM・グループ・前からある会話は動きます。新しい申請のチャットを作る・管理する人を決めるは「関数が v1167 になってから」と出ます。
- 戻すときはもう一度 `work-requests_v1167_index.ts` を貼るだけ（SQL は流し直さなくてよい）。

## 気をつけること

- ② のあとにチャットの SQL（`deploy/chat-v1156` の ②）を流し直すと、読める人が前の決まり（申請を見られる人・GM・CEO の自動）に戻ります。③ の 1・3・4 が NG になったら、添付の ② → この ② の順にもう一度流してください。
- ② が外した「自動で入っていた人」を戻す SQL もありません（戻すと今より多く読める人が出るため）。必要な人は、その会話を管理する人が「人を加える」で加えてください。
