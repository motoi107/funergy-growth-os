# 新しいログインの試し（v1183・段階 1）を入れる手順

GM・CEO が名前で選んだスタッフだけが試します。ほかの人は今までどおり PIN のログインのままです（試す人も PIN のログインは使えます）。仕様：`docs/DEVICE_LOGIN_V1183_JA.md`

- 試す人は、LINE かテキストで届いた**招待のリンク**（48 時間・1 回だけ）を自分の端末で開き、**自分の PIN** を入れて端末を登録します。
- 次からは、その端末で開くだけで入れます（PIN なし）。30 日開かなかった・ログアウトした・「開くたびに PIN」にした・経理の人は、PIN を聞きます。登録は 90 日まで。1 人 5 台まで。
- GM・CEO はまだ試せません（段階 2：管理者セキュアページと同じメールとパスワード）。

使うファイル：

| 番号 | ファイル | どこで |
|---|---|---|
| ① | `1_最初に確認_読むだけ.sql` | Supabase の SQL Editor |
| ② | `2_SQL.sql` | Supabase の SQL Editor |
| ③ | `3_確認_読むだけ.sql` | Supabase の SQL Editor |
| ④ | `device-login_v1183_index.ts`（非公開・リポジトリには無い・Claude が直接渡す） | Supabase の Edge Functions（新しく作る） |

## A. Supabase

1. **SQL Editor に ① を貼って Run。**「STOP」が無ければ次へ。5 の数が 0 なら、GM・CEO のメールのアカウントがありません（「ログインの試し」の画面はメール認証で開くため。Claude に）。
2. **SQL Editor に ② を貼って Run。**「Success」なら次へ。表を 5 つ・関数を 25 足します。社員の表・manager_auth は読むだけで、何も書き換えません。2 回流しても同じです。
3. **SQL Editor に ③ を貼って Run。**「result」に NG が無ければ次へ。
4. **Edge Functions で新しい関数を作る。**
   - 名前は **`device-login`**（この名前ちょうど）。
   - 中身は ④ を全部貼る。
   - **Verify JWT は OFF**（ほかの関数と同じ。だれが頼んでいるかは関数の中で確かめます）。
   - Deploy。Secrets は足さなくてよいです（auth-pin と同じ鍵をそのまま使います）。
   - ④ はリポジトリの `supabase/functions/device-login/index.ts` ではありません（そちらはログインの印を作る部分が無いので、登録すると「まだ使えません」になります）。

## B. GitHub

5. **この PR をマージ**（アプリ v1183。#180 の v1182 を先に）。
6. **試す人と GM・CEO の端末を 1183 に**（「更新」）。ほかの人の画面は、ログイン画面の下に「招待のリンクで登録」が 1 行増えるだけです。

## C. 始める（GM・CEO）

7. **従業員マスター › 「ログインの試し」**（GM・CEO だけに出ます）→ メール認証（Invoice取込・業務Bot と同じメールとパスワード）。
8. **「足す人を選ぶ」で 1 人選んで「足す」→「招待のリンク」。**
   - 出たリンクを **LINE**・**テキスト**・**コピー** でご本人にだけ送ります（グループには送らない）。
   - リンクは 48 時間・1 回だけ。画面を閉じると、そのリンクはもう出せません（もう一度「リンクを作り直す」と、前のリンクは使えなくなります）。
9. **ご本人が自分の端末でリンクを開く** → 名前を確かめて、自分の PIN を入れる →「この端末を登録してログイン」。
   - **PIN が初期のまま（0000）の人は登録できません。**先にいつものログインで入って、マイページの「PIN設定」で変えてもらいます。
   - ホーム画面に追加したアプリで使う人は、リンクをコピーして、アプリのログイン画面の「招待のリンクで登録」に貼ります（iPhone では、Safari とホーム画面のアプリは別の入れ物のため）。
10. **最初は 1〜2 人で数日**試して、困ったことがあれば Claude に。

## D. 確かめる

11. ご本人の端末：アプリを閉じてもう一度開くと、PIN なしで入れること。マイページに「この端末のログイン（試し）」があること。
12. GM・CEO：「ログインの試し」の一覧で、その人が「登録済み・端末 1 台」になっていること。
13. ③ をもう一度流して、9 の数（試す人・使える端末）が増えていること。

## 困ったとき

- **1 人だけ止めたい**：「ログインの試し」で「試しから外す」（その人の招待と端末は使えなくなる・いつもの PIN のログインは使える）。端末だけなら「端末」→「外す」。
- **全員止めたい**：SQL Editor で `止める.sql`（招待と端末をすべて止めて、試す人を空にする。記録は残す）。
- **関数を止めたい**：Edge Functions の `device-login` を消す（アプリは「この新しいログインは、まだサーバーで使えるようになっていません」と出し、いつもの PIN のログインになります）。
- ご本人が「使えなくなりました」と出たとき（ブラウザのデータを消した・端末を外された・90 日）：いつもの PIN で入れます。続けたい人は GM・CEO がもう一度招待します。
- 覚えのない端末が一覧にあったとき：ご本人がマイページ › 端末と設定で「外す」か「すべての端末からログアウト」、または GM・CEO が「端末」→「外す」。
