# チャットを止めたいとき（v1156）

いちばん軽い止め方は **関数を前の版に戻すこと**です。会話・メッセージはサーバーにそのまま残ります。

1. Edge Functions → `work-requests` に、前の非公開のファイル `work-requests_v1155_index.ts` を貼って Deploy（Verify JWT は OFF）。
2. アプリのチャットの画面は「チャットのサーバー（関数 work-requests）が前の版です」と出て、何も読み書きしません。申請（ワークセンター）は今までどおり動きます。
3. また使うときは `work-requests_v1156_index.ts` を貼り直すだけ（SQL は流し直さなくてよい）。

会話・メッセージそのものを消す SQL は用意していません（消すと戻せないため）。消したいときは Claude に言ってください。
