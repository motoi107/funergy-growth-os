## 困ったとき

- **D のどこかで保存・表示がおかしくなった**：その版の `戻す/` の SQL（`deploy/<版>/戻す_SQL.sql`）を流す（その版の ③ だけを戻す。ほかは変えない）→ 画面の写真と ④ の表を Claude に。
- **関数を前に戻すとき**は、**先に戻す SQL を流してから**（v1152 なら `deploy/secure-notifications-v1152/戻す_SQL.sql` → `deploy/change-signal-v1151/2_関数_secure-state_index.ts`）。SQL を戻す前に関数だけ戻すと、だれも通知などを読めなくなります。
- 保存がいつもより遅い・保存できない（v1151 の ③ のあと）：`deploy/change-signal-v1151/戻す_SQL.sql`（見張りを外すだけ。保存はすぐ元どおり）。
- 「〇〇を変えられるのは GM・CEO です（サーバーが断りました。送信待ちに残しています）」：その端末のログインがその役割と確かめられていないか、更新の前に送れていなかった変更です。それぞれの版の手順の「困ったとき」を見るか、Claude に。
