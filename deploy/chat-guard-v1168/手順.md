# チャットの守り（個人の暗証番号・グループのキー・プッシュ通知）を入れる手順（v1168）

UI案79 の答え（1〜6 A）のうち、v1167 で入れなかった 3 つです。

- **個人のチャット暗証番号**：ログインの PIN とは別の 4〜8 桁。本人が決める・変える・外す（初めはオフ）。決めた人は、チャットを開くとき・ロックのあとに入れます（どの端末でも）。開けていないと、サーバーは一覧・会話・画像・ファイル・合図を返しません（新着の数だけ）。忘れたら、ロックの画面の「暗証番号を忘れた」→ ログインの PIN で本人を確かめて外します。
- **グループのキー**：グループ・申請のチャットに、その会話を管理する人が決める（作るときにも決められる）。参加者は開くときにキーを入れます。参加者でない人はキーを知っていても入れません。キーを変えると、前に開けた端末ももう一度キーを聞かれます。忘れたら管理する人が新しいキーを決めます。
- **プッシュ通知**：本人が「チャットの守り」の画面で「この端末で受け取る」を押した端末だけ。出るのは「新着メッセージがあります」だけ（送った人・会話の名前・本文・画像は出ません）。iPhone はホーム画面に追加したアプリ（iOS 16.4 以上）。ログアウトで止まります。

暗証番号・キーはどちらも**そのままでは置きません**（PBKDF2 の印だけ）。続けて 5 回間違えると止まります（15 分・30 分・1 時間…最大 24 時間）。

先に入っていること：チャット（`deploy/chat-v1156`）・添付（`deploy/chat-files-v1161`）・チャット改修（`deploy/chat-ui79-v1167`）。

## A. Supabase

1. **SQL Editor に ① を貼って Run。**「STOP」が 1 つも無ければ次へ。
   - 1 が STOP なら、先に `deploy/chat-ui79-v1167`（とその前の 2 つ）。3・4 が STOP なら Claude に。
   - 2 が 3 なら初めて、4 ならもう入っています（② をもう一度流しても同じ）。
2. **SQL Editor に ② を貼って Run。**「Success」なら次へ。
   - 「STOP: 先にチャット…」なら何も変わっていません。1 の案内のとおりに。ほかのエラーなら止めて、エラーの文を Claude に。
   - ② だけでは何も変わりません（暗証番号・キーを決めた人がいないあいだは v1167 と同じに動きます）。
3. **SQL Editor に ③ を貼って Run。**「result」の列に NG が 1 つも無ければ次へ。
   - 1・4 が NG なら、② のあとにチャットの SQL（v1156・v1161・v1167 の ②）を流し直しています。→ 添付の ② → チャット改修の ② → この ② の順にもう一度。
4. **Edge Functions → Secrets（Project Settings › Edge Functions）に ⑤ の 3 つを足す**（`CHAT_VAPID_PUBLIC`・`CHAT_VAPID_PRIVATE`・`CHAT_VAPID_SUBJECT`。名前と値はファイルのとおり）。
   - 足さなくても暗証番号・キーは使えます（プッシュ通知だけ「サーバーの準備がまだ」と出ます）。
   - `CHAT_VAPID_PRIVATE` は秘密です（GitHub・LINE・Claude との会話に貼らない）。
5. **Edge Functions で `work-requests` を開いて、④ の中身を全部貼って Deploy（Verify JWT は OFF）。**
   - ② の前に ④ を貼っても壊れません（そのあいだ守りの画面は「サーバー（SQL）が v1168 になってから」と出ます）。

## C. アプリ

7. **全員の端末で、アプリの「更新」を押す。**ログイン画面の版が 1168 になれば OK。
   - **暗証番号を決める人は、自分の端末をすべて 1168 にしてから決めてください。**1167 以前の端末では、暗証番号を決めた人のチャットが空に見え、送れません（サーバーが断るため。1168 にすると暗証番号を聞かれます）。
   - キーのある会話は、1167 以前の端末では開けません（「うまくいきませんでした（chat_key_required）」と出ます）。
8. **確かめ（本番・Moto さん）**：
   - チャットの 🛡（チャットの守り）→「暗証番号を決める」→ 2 回入れる →「今すぐロック」→ 暗証番号で続ける（違う番号では「あと 4 回」）。
   - 別の端末（PC とスマホなど）でログイン → チャットが暗証番号を聞く（新着の数だけ出る）。
   - グループを作るときに「キーで守る」→ ほかの参加者の画面ではグループの名前だけ・開くとキーを聞く → キーで開く。管理する人が「参加者」→「グループのキー」で変える → 開いていた人ももう一度。
   - iPhone（ホーム画面のアプリ）で 🛡 →「この端末で受け取る」→ 許可 → ほかの人が送ると「新着メッセージがあります」→ 押すとその会話が開く。
   - ロックの画面の「暗証番号を忘れた」→ ログインの PIN → 暗証番号が外れる。

## 決まり（UI案79 の答え・依頼書の 6）

- 個人のチャット暗証番号はログインの PIN とは別・本人が任意に決める（初めはオフ）・決める・変える・外すは本人（変える・外すは今の暗証番号が要る）。
- グループのキーはグループごとに任意・管理する人が作るとき／設定で決める・変える・外す。参加者でなければキーがあっても入れない。両方あれば両方。
- キーを変えたら、開いている端末でもう一度聞く。暗証番号を変えたら、ほかの端末ではもう一度聞く。
- 暗証番号を忘れた → 本人の確かめ（ログインの PIN・サーバーの auth-pin）で外す。キーを忘れた → 管理する人が決め直す。
- 暗証番号・キー・開けた印はそのまま置かない・ログに出さない。続けて 5 回間違えると止める。
- 店の共有 PC：ロックのあと・ログインし直したあと、暗証番号を決めている人には暗証番号を聞く。決めていない人はログインの PIN（v1167 のまま）。ログアウトでこの端末の開けた印を消し、プッシュ通知も止める。
- プッシュ通知は「新着メッセージがあります」だけ。会話から外された・抜けた人には送らない。
