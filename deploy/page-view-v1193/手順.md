## 入れる順番（この順番で）

1. **`1_確かめ_読むだけ.sql` を流す**（Supabase › SQL Editor）
   - 1 行目か 2 行目が STOP なら止めて、表を Claude に貼ってください（同じ名前の表が別の形で、もうあります）。
   - 3 行目は今の「Grade別の非表示ページ」の設定があるか、4 行目は役職ごとの非表示ページの数です（info）。どちらも消しません。あとで GM・CEO が新しいタブで確かめます。
2. **`2_SQL_画面の表示.sql` を流す**
   - 2 つの表は公開の鍵では読めず、書けません。保存はサーバーの鍵の関数 `pv_save` だけです。2 回流しても同じです。
   - 入れた時点ではどの画面も変わりません（設定の行はまだありません）。
3. **`3_確かめ_読むだけ.sql` を流す**
   - 全部 OK か info なら入っています。NG があれば表を Claude に貼ってください。
4. **関数 secure-state を差し替える**
   - Supabase › Edge Functions › secure-state を開き、`4_関数_secure-state_index.ts` の中身をそのまま貼って Deploy します（Verify JWT は OFF のまま）。
   - この 1 ファイルは `node scripts/build-secure-state-one.mjs` で作ったものです（v1192 の人件費の合計も入っています）。手で直さないでください。
   - 前の版のアプリ（1192 まで）の動きは変わりません。前の版は画面の表示の設定を読みません。
5. **PR をマージし、全部の端末を 1193 にする**
   - ログイン画面の版が 1193 になっていることを確かめてください。
   - まだ設定が保存されていないので、どの端末も今までどおりです。
6. **GM・CEO が「画面の表示」タブで初めて保存する**（1193 の PC で）
   - 設定 › 承認・閲覧設定 › 画面の表示。初めは今の決まり（役職のメニューと「Grade別の非表示ページ」）を写した値が出ます。
   - 「新しく見えるようになる画面」（印「新」）を確かめ、要らなければ非表示にしてから、理由を書いて保存します。
   - 保存した時点から全部の端末がこの設定で表示します（10 分以内・ログインのたびに読み直す）。「Grade別の非表示ページ」のカードは、この設定へ案内するだけになります。
   - スマホでは見るだけです（保存は PC で）。

## 入れたあとに確かめること（実機）

- G1・G2・G3・店長・AM・経理の端末で、メニューが「画面の表示」の表と同じか。
- 「新しく見えるようになる画面」を開くと「見るだけ」の帯が出て、保存・確定・削除が止まるか。
- 「スタッフから確認」で 1 人の見え方を確かめ、人ごとの「表示／非表示」を保存すると、その人の端末だけが変わるか。
- 「変更の記録」に、だれが・いつ・何を変えたかが残るか。前の版に戻せるか。

## 止めるとき・戻すとき

- **すぐ今までの決まりに戻したいとき**：`止める_SQL.sql` を流します。全部の端末が 10 分以内（ログインし直せばすぐ）今までの決まりで表示します。設定と記録は残るので、`もう一度使う_SQL.sql` で戻せます。
- 関数も戻すときは、`deploy/labor-totals-v1192/4_関数_secure-state_index.ts` を secure-state に貼ります。1193 のアプリは「関数が前の版」と判断して、今までの決まりで表示します（v1192 の人件費の合計はそのまま使えます）。
- SQL も戻すときは、**関数を戻したあとに** `戻す_SQL.sql` を流します。保存の関数だけを消し、表と記録は残します。

## 困ったとき

- 「画面の表示」タブに「サーバーの関数が前の版です」と出る：4 の Deploy を確かめてください。
- 「データベースがまだです」と出る：2 の SQL を確かめてください（`3_確かめ_読むだけ.sql`）。
- 保存で「ほかの人が先に保存しました」と出る：読み直して、自分の変更を入れ直してから保存してください（上書きはしません）。
- ある人のメニューに画面が出ない：「スタッフから確認」でその人を選び、理由（グレード・人ごと・指定スタッフ限定・今までの決まり）を見てください。
- この設定は「画面に出すか」だけです。データを読めるかはサーバーの決まりのままです（見るだけの画面でデータが出ないことがあります）。
