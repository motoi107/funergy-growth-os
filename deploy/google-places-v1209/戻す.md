# Google の評価・口コミ（Places API）を止めたいとき（v1209）

いちばん軽い止め方から順に：

1. **Google（Places API）を呼ばないようにする**：SQL Editor で `止める_Places.sql` を Run。会議のカードの「見る」も、店を探すのも、Google を呼ばずに「上限」と出ます。店の結び・回数は残る。また始めるときは、同じファイルの「再開」の行（`update public.gr_settings set places_day_max = 40, search_day_max = 40 where id = 1;`）。
2. **鍵を外す**：Supabase の Secrets から `GOOGLE_PLACES_API_KEY` を消す。アプリは「Places API の鍵がサーバーに入っていません」と出し、Google を呼びません。Google Cloud で API キーを無効にしたときは、Google が断り、アプリは「Google が断りました」と出します（呼んだ回数には数えます）。
3. **関数を v1157 に戻す**：Edge Functions → `google-reviews` に `deploy/google-reviews-v1157/4_関数_google-reviews_index.ts` を貼って Deploy。
   - **気をつけること**：v1157 の関数には、回数の上限と「見られる店だけ」の確かめがありません（関数に入れる人ならどの店の評価・口コミも見られる・KPI の数も全店）。v1209 のアプリは押したときだけ呼ぶので、勝手に呼ぶことはありません。アプリも v1157 まで戻すと、会議のカードを描くたびに呼びます（料金）。
4. **アプリを前の版に戻す**：この PR を revert。

SQL（② で足した欄・回数の表・関数）は戻さなくても、v1157 の関数は使いません。消したいときは Claude に言ってください（回数の記録が消えます）。
