## A. Supabase（SQL を先に、関数はそのあと）

1. **SQL Editor に ① を貼って Run。**「STOP」が 1 つも無ければ次へ。
   - 1 が STOP なら、先に `deploy/google-reviews-v1157/` の ② から。
   - 4 に店の ID が出たら、その店は店舗マスターに無い（使っていない）のに Google の店が結んである。②のあと KPI設定で「外す」か、Claude に。
2. **SQL Editor に ② を貼って Run。**「Success」なら次へ。エラーなら止めて、エラーの文を Claude に。2 回流しても同じです。
3. **SQL Editor に ③ を貼って Run。**「result」の列に NG が 1 つも無ければ次へ。
4. **Edge Functions → `google-reviews` → コードを ④ の中身に全部置き換えて Deploy。Verify JWT は OFF のまま。**
   - 関数を先に入れてしまっても、② が入るまでは Google を呼ばずに「Google の口コミのサーバー（SQL）が前の版です」と出るだけです（壊れない・料金なし）。
   - v1209 のあとは v1157 の ③ を使わない（4 の行が「21 個」ではないので NG になる）。v1209 の ③ を使う。
   - あとで v1157 の ② を流し直したら、v1209 の ② ももう一度（店舗マスターの確かめが外れる＝③ の 7 が NG）。

## B. Google Cloud（料金の守り）

5. **1 日の割り当て（quota）を下げる。**「API とサービス」→「Places API (New)」→「割り当てとシステム上限」で、店の詳しい情報（Place Details／GetPlace）と店を探す（Text Search／SearchText）の 1 日のリクエスト数を、サーバーの上限より少し上（例：どちらも 60）にする。サーバーの上限が効かなくなっても、Google 側で止まります。項目の名前は Google の画面で少し違うことがあります。
6. **予算のアラート。**「お支払い」→「予算とアラート」で月の予算（例：$10）とメールの知らせ。アラートは知らせるだけで、呼び出しは止めません（止めるのは 5 とサーバーの上限）。
7. **「アプリケーションの制限」は「なし」のまま。**
   - IP アドレスの制限：Supabase の Edge Functions には決まった送信元の IP アドレスが無いので、使えません（使うなら決まった IP のある中継のサーバーを別に用意する＝費用と管理が増える）。
   - HTTP リファラー（ブラウザ用）・Android／iOS アプリ（スマホのアプリ用）：サーバーからの呼び出しには使えません。
   - かわりに：鍵はサーバーの Secrets だけ・API の制限は Places API (New) だけ（今のまま）・5 と 6・サーバーの上限。
8. 鍵を作り直したときは、Secrets の `GOOGLE_PLACES_API_KEY` を変えるだけ（関数を作り直さなくてよい）。

## 上限と料金（太平洋時間で日・月を区切る＝Google の請求と同じ）

| | 1 日 | 1 店 1 日 | 1 人 1 日 | 月 |
|---|---|---|---|---|
| 店の評価と口コミ（Place Details） | 40 回 | 10 回 | 25 回 | 900 回 |
| 店を探す（Text Search・GM・CEO だけ） | 40 回 | — | — | 400 回 |

- 数えるのは「Google を呼んだ回数」（Google が断った回も数える）。上限なら Google を呼ばずに「今日の Google への問い合わせの上限に達しました」などと出ます（太平洋時間の 0 時＝ハワイの 21〜22 時に戻る）。GM・CEO の画面に今日・今月の回数が出ます。
- 上限を変えるとき（SQL Editor）：`update public.gr_settings set places_month_max = 900 where id = 1;` のように欄を変える。0 にするとその呼び出しを止めます。
- 料金がかかる条件：
  - 店の評価と口コミ（評価・件数・口コミを取る）は Google の「Place Details Enterprise + Atmosphere」。月 1,000 回までは無料、こえた分は 1,000 回あたり約 $25。月の上限 900 回なら無料の中です。
  - 店を探す（名前・住所を取る）は「Text Search Pro」。月 5,000 回までは無料、こえた分は 1,000 回あたり約 $32。月の上限 400 回なら無料の中です。
  - 無料の回数は Google の請求先（請求アカウント）ごとです。同じ請求先でほかに Places API を使っていれば、その分も数えられます。
  - Business Profile（v1157）の口コミの取り込みは Places の料金ではありません。
