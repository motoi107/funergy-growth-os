1. **SQL**：Supabase の SQL Editor で `1_追加のSQL.sql` を流す（関数 5 つと、app_settings の見張り 1 つを足すだけ。データ・ほかのキーは変えない。2 回流しても同じ）。
   「STOP」と出たら何も変わっていないので、その表を Claude に。
2. **確かめ（読むだけ）**：`2_確かめ_読むだけ.sql` を流す。`setup` の行がすべて OK。`data` の行は月・店ごとの「確定・暫定」の数だけ（金額は出ない）。

   表は Claude との会話にだけ貼る（公開の PR・Issue には貼らない）。

## 気をつけること（運用）

- **確定にしてしまった月を暫定に戻す道は無い**（確定はいつも勝つ）。ファイル名に「暫定」が無いまま暫定のブックを取り込むと、その店・月は確定版を取り込むまで確定のまま。直すのは確定版を取り込むか、Claude が渡す SQL で。取り込む前の画面の「確定」「暫定」を確かめる。
- **売上が 0 の月**（休業など）は確定の印にならない（暫定と同じ順位）ので、あとの暫定に負けることがある。
- 同じ種類（どちらも確定・どちらも暫定）で時刻（`_at`）まで同じときの決め方は、アプリ（文字の並び）とデータベース（新しく書いたほう）で違う。アプリは時刻を前より必ず後にするので、ふつうは起きない。
