## 関数の貼り方（Edge Function）

1. Supabase → 左のメニューの **Edge Functions**
2. 一覧の **mid-review** を開く（ケース 1 でまだ無ければ、新しく `mid-review` という名前で作る）
3. コードを編集する画面を出す（**Edit function** / **Code** / **Via Editor** のどれか）
4. 出ているコードを **全部消す**
5. `C_関数_index.ts` の中身を **全部コピーして貼る**（貼るのはこの 1 ファイルだけ。ファイル名は `index.ts` のまま）
6. **Deploy** を押す
7. 新しく作った場合だけ：その関数の設定で **Verify JWT を OFF**（ログインは関数の中で確かめます。Invoice取込と同じ）

## 困ったとき

- **SQL がエラーになった**：エラーの文をそのまま Claude に貼ってください。流しかけでも、表や行は壊れません（B は関数 3 つを置き換えるだけ、2 回流しても同じ結果）。
- **関数を入れたあと画面が「読み込み中…」のまま**：まだ SQL（B）を流していない、または土台（A）が入っていない状態です。`最初に確認.sql` の数字を見てください。
- **直しを取り消したい**：`db/mid-review-fixes-revert.sql` を流すと、関数 3 つが土台（A）のときの中身に戻ります。そのときは Edge Function も前の版に戻してください。
- **全部やめたい**：アプリの設定で「非公開確認を OFF」にすれば、ほかの画面は何も変わりません。表ごと消すのは `db/mid-review-rollback.sql`（本番のレビューが 1 件でもあると止まります）。

## 入れると何が変わるか

- 変わるのは中間レビュー（予実 › 中間レビュー）だけです。ほかの画面・業務データ・Toast・Invoice取込には触りません。
- B を流したあと、**更新していない端末（v1066 のまま）からは返信を送れません**（「うまくいきませんでした（drafts_changed）」）。ブラウザを再読込すれば送れます。
- 店舗公開と通知は OFF のままです（店長はまだ入れません）。
