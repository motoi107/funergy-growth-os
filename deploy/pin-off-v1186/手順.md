# v1186 GM・CEO・経理は PIN でログインしない — 入れる手順

仕様：`docs/PIN_OFF_V1186_JA.md`。Moto さん 11/16 23:24 HST「PINでのログインやめます」。

- GM・CEO・経理は、名前を選んだあと**メールとパスワードだけ**で入る（ログインの画面に「PIN でログイン」を出さない）。
- PIN が要るところ（割引・チャットの「続ける」など）は今までどおり PIN。
- 事務Crew・ほかの人は今までどおり PIN。
- GM・CEO はチャットで操作が無くてもロックしない（PIN で入った日も。v1167 から同じ）。

## 入れる前に（v1185 が入っていること）

`deploy/email-login-v1185/` の ①②③ が済んでいて、GM・CEO・経理がメールとパスワードで入れること。

## 順番

1. **① `1_最初に確認_読むだけ.sql`**（読むだけ）。
   - STOP が 1 つも無ければ次へ。
   - 4 が STOP：その人のメールのアカウントを作って社員と結ぶ（Claude に）。
   - 5 が「注意」：その人に一度、名前を選んで**メールとパスワードで**入ってもらう（今のアプリでもできる）。①をもう一度流して 5 が OK になるまで。
   - 4〜7 の行は名前が出ます。Claude との会話にだけ貼る。
2. **関数を 3 つ入れる**（どれも Claude が直接渡す非公開の 1 ファイル。リポジトリには置かない）。SQL の前に入れても何も変わりません（SQL がまだのあいだは止めない）。
   - Edge Functions → **device-login** → Code に `device-login_v1186_index.ts` を全部貼る → Deploy（Verify JWT は今のまま OFF）。
   - Edge Functions → **emp-private** → `emp-private_v1186_index.ts` → Deploy。
   - Edge Functions → **auth-pin** → `auth-pin_v1186_index.ts` → Deploy。**まだ作っていません**（今の auth-pin のソースを Claude に添付 → Claude が作って渡す）。
3. **マージ**（アプリ 1186）。
4. **端末をすべて 1186 に**（GM・CEO・経理の端末と、店のタブレットも）。アプリを開いて「更新」→ ログインの画面の版が 1186。
5. **② `2_SQL.sql`**。ここから GM・CEO・経理は PIN で入れなくなります。
   - 「STOP: … 人が、メールのアカウントと結ばれていません」と出たら何も変わっていません。①の 4 に戻る。
6. **③ `3_確認_読むだけ.sql`**（読むだけ）。NG が 1 つも無ければ OK。
7. **確かめる**：GM の端末でログアウト → 名前を選ぶ → 「PIN でログイン」が無く、メールとパスワードの段になる → 入れる。割引の PIN とチャットの「続ける」は今までどおり PIN で通る。

## 困ったとき

- **PIN に戻す**：`PIN_を戻す.sql`（スイッチを外すだけ。表・関数・記録は残す）。もう一度止めるときは ② をもう一度。
- **メールのログインを止めた**（v1185 の `止める.sql`）ときは、PIN も自動で戻ります（だれも入れなくなるのを防ぐ）。
- 関数を前に戻すときは、② のあとでも前の 1 ファイルを貼ればよい（device-login は v1185、emp-private は v1185、auth-pin は今のもの）。そのときは PIN でまた入れるようになります（画面だけ止めた状態）。

## 気をつけること

- **端末を 1186 にしてから ②**。1185 以前のアプリのまま ② を流すと、GM・CEO・経理が PIN を押したとき「通った」ように見えて画面は開くが、ログインの印が無いので給与・成長カルテなどが読めない（secure-state などが断る）。そのときはアプリを「更新」してメールとパスワードで入り直す。
- **auth-pin v1186 を入れないまま ② を流すと、止まるのは画面だけ**です（1186 のアプリは PIN のボタンを出さないが、1185 以前のアプリや直接の呼び出しでは PIN でまだ入れる・給与だけは emp-private が PIN では渡さない）。
- 社員の表で、列と中身の役割が違う人（①の 6）：どちらかが GM・CEO・経理なら PIN を止めます。
- 経理のログインの試し（端末＋PIN・①の 7）は、② のあと止まります（メールとパスワードで入る）。
