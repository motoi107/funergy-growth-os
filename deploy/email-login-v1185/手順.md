# GM・CEO・経理のメールとパスワードのログイン（v1185・ログインの段階 2）を入れる手順

GM・CEO・経理（manager_auth の役割 ceo・gm・office）は、ログイン画面で名前を選ぶと、PIN の代わりに**管理者セキュアページと同じメールとパスワード**を入れます。仕様：`docs/EMAIL_LOGIN_V1185_JA.md`

- 端末には覚えません。アプリを開くたびにメールとパスワードを入れます（Moto さん 11/16「開くたびに入れる」）。
- 試しのあいだは、画面の「PIN でログイン（試しのあいだ）」で今までどおり PIN でも入れます。
- 新しい端末で入ると、ご本人とほかの GM・CEO にアプリの知らせが出ます。
- マイページの「管理者セキュアページ」は、メールを入れ直さずに開けます（「アプリに戻る」で戻る）。
- 事務Crew・店長・スタッフ・店舗のログインは今までどおり PIN です。PIN が要るところ（割引など）も今までどおりです。

## A. Supabase

1. **SQL Editor に ① を貼って Run。**「STOP」が無ければ次へ。
   - 1 が STOP：v1183（ログインの試し）の SQL がまだです。先に `deploy/device-login-v1183/` の ①②③ を流してから、もう一度 ①。
   - 6 が 0 でない：社員の行と結ばれていない GM・CEO・経理のメールのアカウントがあります。その人はメールでは入れません（「このメールでは入れません」と出て、PIN で入ります）。結ぶ SQL は Claude に（表の結果は Claude との会話にだけ貼る）。
2. **SQL Editor に ② を貼って Run。**「Success」なら次へ。表を 1 つ・関数を 3 つ足します。社員の表・manager_auth は読むだけ。知らせ（app_state の notifications）に、新しい端末のときだけ 2 つ足します。2 回流しても同じです。
3. **SQL Editor に ③ を貼って Run。**「result」に NG が無ければ次へ。8 は「結ばれている数 / GM・CEO・経理の数」です。
4. **Edge Functions → `device-login` の中身を ④ に差し替えて Deploy。**
   - まだ `device-login` が無いときは、この名前で新しく作る（Verify JWT は OFF）。
   - ④ はリポジトリの `supabase/functions/device-login/index.ts` ではありません（そちらはログインの印を作る部分が無いので「まだ使えません」になります）。
   - v1183 の 1 ファイルの中身はそのまま入っています（ログインの試しはそのまま動きます）。
5. **Edge Functions → `emp-private` の中身を ⑤ に差し替えて Deploy。**
   - 給与・人件費を、PIN の代わりにログインの印で読めるようにします（v5 からの違いはそこだけ。PIN の道・役職・返す中身は v5 のまま）。
   - 入れないと、メールで入った人は入ったあとに **PIN を 1 回聞かれます**（給与を読むため）。

## B. GitHub

6. **この PR をマージ**（アプリ v1185）。
7. **GM・CEO・経理の端末を 1185 に**（「更新」）。

## C. 確かめる

8. ログイン画面で事業所 → 自分の名前（盾の印）→ メールとパスワード →「ログイン」。PIN を聞かれずに入れること。
9. 従業員マスター・人件費率で給与が出ること（PIN を聞かれたら ⑤ がまだ）。
10. 新しい端末なら、知らせ（本人とほかの GM・CEO）が出ること。
11. マイページ →「管理者セキュアページ」→ メールを入れ直さずに開く →「アプリに戻る」。
12. ③ をもう一度流して、9 の数（メールで入った回数・端末）が増えていること。

## 困ったとき

- **メールとパスワードのログインを止めたい**：SQL Editor で `止める.sql`（関数を外す・表と記録は残す）。名前を選んでメールを入れると「このログインは、まだサーバーで使えるようになっていません。「PIN でログイン」をお使いください。」と出て、PIN で入れます。もう一度始めるときは ② をもう一度。
- **関数を前に戻したい**：`device-login` は v1183 の 1 ファイル、`emp-private` は v5 に戻す（どちらもアプリは PIN で入れます）。
- **パスワードを忘れた**：管理者セキュアページと同じアカウントです。今までどおり管理者に頼みます（アプリの「パスワードを忘れたとき」にも出ます）。
- **覚えのない「新しい端末でログインしました」**：すぐにパスワードを変えて、マイページの「すべての端末からログアウト」。
- **アカウントを止めた・退職にした**：その人は次の取り替え（最長 30 分）でログアウトします。
- v1183 の ③（`deploy/device-login-v1183/3_確認_読むだけ.sql`）の 4 は、v1185 の関数を数えません（v1185 を入れても OK のまま）。
