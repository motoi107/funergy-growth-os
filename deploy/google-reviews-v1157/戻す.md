# Google の口コミを止めたいとき（v1157）

いちばん軽い止め方から順に：

1. **毎日の取り込みだけ止める**：SQL Editor で `止める_毎日の取り込み.sql` を Run。口コミ・店の結び・つなぎは残る。また始めるときは `5_毎日の取り込み_cron.sql`。
2. **Business Profile を切る**：KPI設定 →「Google の口コミ」→「切る」（GM・CEO）。鍵（refresh token）を忘れる。取った口コミと店の結びは残る（つなぎ直せば続きから）。Google アカウントの「サードパーティのアクセス」からも外せる。
3. **関数を止める**：Edge Functions → `google-reviews` を削除。アプリは「Google の口コミのサーバー（関数 google-reviews）がまだありません」として、今までどおり手入力に戻る（会議のカード・KPI は手入力の数）。SQL の表はそのまま残る。
4. **アプリを前の版に戻す**：この PR を revert。表・関数はあっても使われない。

表そのもの（口コミ）を消す SQL は用意していません（消すと戻せないため）。消したいときは Claude に言ってください。
