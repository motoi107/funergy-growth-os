Funergy+ は、Funergy Group Inc.（以下「当社」）のスタッフが、店舗と本部の業務に使う社内向けのアプリです。このポリシーでは、Funergy+ の iPhone アプリと Web 版（funergy-plus.com）が集めて保存する情報と、その使い道を説明します。

1. Funergy+ を使う人

Funergy+ は当社のスタッフ向けのアプリです。アカウントは会社が用意し、だれでも登録できる窓口はありません。応募者と新しく入る人の情報も、下に書くとおりアプリで扱います。

2. 集めて保存する情報

ログインと安全のための情報

  • お名前（ログインの画面で選んだもの）と PIN。PIN は当社のサーバーが確かめます。
  • 一部の管理者・経理のアカウント：メールアドレスとパスワード（認証のサービスが扱います）。
  • パスキーと登録した端末：公開鍵、端末の名前、登録した日時と最後に使った日時。秘密鍵は端末から出ません。
  • メールアドレスに送るログインのコードと招待のリンク。
  • ログインの記録：日時、結果、IP アドレス、ブラウザーや端末の情報（ユーザーエージェント）。

スタッフの情報

  • 氏名、社員番号、役割、グレードと肩書き、所属の店と応援の店、雇用の形と状態。
  • 入社日、初出勤日、休職の期間、退職日などの日付。
  • メールアドレスと電話番号。
  • 生年月日、会社カードの下 4 桁、医療保険・歯科保険の加入と会社負担の保険料。
  • 給与の情報：時給または月給と、それに関わる設定。
  • 当社の POS（Toast）に出るお名前。

新しく入る人の手続き（オンボーディング）

新しく入る人が招待のリンクから手続きをすると、次の情報を集めます：氏名、住所、電話番号、メールアドレス、生年月日、社会保障番号（SSN）、ビザ・就労資格の情報、本人確認書類の画像（パスポート、運転免許証、SSN カード）、署名、会社の規定への同意、I-9 の確認の状況。これらは別のサーバーの機能に送り、アプリのふだんのデータの同期には含めません。本人確認書類の画像は当社のデータベースに保存し、ほかの事業者には送りません。

採用

管理者が応募者を記録します：氏名、応募した店と職種、電話番号、メールアドレス、応募の経路、応募日、メモ、職歴、スキル、履歴書のファイル名。

業務の記録

  • シフトと勤務の予定。Toast から取り込む出退勤・売上・支払い・チップのデータ。労働時間と人件費。
  • 現金のチップとチップの配分。
  • 売上、予算、財務の資料。棚卸し、仕入れ、レシピと原価。
  • 請求書とレシート（写真と PDF を含む）。
  • 経費と休暇の申請、ガソリン代の申請（移動ごとの出発地・目的地・距離を含む）、業務の依頼と、それらの承認。
  • 毎日の業務のチェック、日報とそれに付けた写真。会議の資料と目標。
  • 社員割引の利用（だれが・グレード・店・日時）。

評価と育成

Career Score の評価、成長の記録（グレードと給与の履歴を含む）、中間レビュー、育成の計画と研修の進み具合、賞与の評価と計算。

メッセージ

DM、グループのメッセージ、申請についてのやりとり（@ の宛先、既読の状況、添付の写真と PDF を含む）。メッセージは当社のサーバーに保存し、エンドツーエンドの暗号化はしていません。

通知

対応したブラウザーで通知をオンにすると、ブラウザーが出す通知の宛先を、スタッフの ID と結びつけて保存します。通知は「新着メッセージがあります」だけで、送った人・会話の名前・本文は含みません。

端末の情報と変更の記録

  • アプリが作って端末に置くランダムな端末の印と、ユーザーエージェントから決める端末の種類（パソコン、iPhone、iPad、Android）。
  • だれが・どのデータを・いつ変えたかの記録（スタッフの ID、名前、役割、端末の印と種類）。

端末に保存する情報

速く動かし、通信が弱いときも使えるように、見られるデータのコピーと設定を、端末のアプリまたはブラウザーの保存領域に置きます。

当社の店の口コミ

スタッフが口コミに対応できるように、Google にある当社の店の口コミ（投稿者の表示名、評価、コメント、日付）を取り込みます。

Funergy+ が使わないもの

Funergy+ は端末の位置情報を求めず、連絡先にアクセスしません。このアプリに、広告の SDK と、分析や追跡の SDK は入っていません。カメラと写真は、ご自分で写真を撮る・添付するときだけ使います。

3. 情報の使い道

  • 店舗と本部の毎日の業務：シフト、勤怠、チップ、仕入れ、棚卸し、経理、予算。
  • 人事：採用、入社の手続き、評価、研修、給与と賞与の計算。
  • 社内の連絡と通知。
  • 安全のため：ログインの確認、役割による見られる範囲の制限、ログインと変更の記録。

4. 情報を見られる人

社内でも、役割と店によって見られる範囲を分けています。個人の給与、生年月日、保険などの機微な情報は、権限のある役割にだけ表示し、店の共有端末で見られる範囲も限っています。

権限のあるスタッフは、給与と経理の作業のために、一部の記録（チップ、手当、経費、棚卸しなど）をファイルとして出力できます。

5. 利用している外部のサービス

Funergy+ は、動かすために次のサービスを使います。

  • Supabase：アプリのデータのデータベース、ログイン、ファイルの保存、サーバーの機能。
  • GitHub Pages（GitHub）：Web 版（funergy-plus.com）のファイルを届けます。アプリのデータはここに保存しません。
  • Toast：当社の POS。出退勤、売上、支払いとチップ、品目の数を Toast から自動で読みます。
  • Toast Payroll：当社が使う給与のサービス。Funergy+ は Toast Payroll と直接にはつながっていません。経理の担当者が Funergy+ からデータ（チップ、手当、経費の一覧、新しく入る人の情報）を出力し、手で Toast Payroll に入れます。
  • Intuit QuickBooks：当社の会計システム。請求書のファイルを、会社の Gmail からメールで QuickBooks へ転送します。
  • Google：Gmail（ログインのコード・招待・知らせを送る、請求書を受け取り転送する）、Google ドライブ（請求書のファイルの保存）、Google ビジネスプロフィールと Places（当社の店の口コミと評価）、Google マップ（ガソリン代の申請の住所の検索と距離）。
  • Anthropic：請求書と小切手の画像の中身を自動で読み取るため、それらを Claude API に送ります。
  • LINE：業務の知らせ（スタッフの名前や勤務の内容を含むことがあります）を、社内の LINE グループに送ります。
  • QR コードのサービス（api.qrserver.com）：QR コードの画像を作るため、入社の手続きの招待のリンクをこのサービスに送ります。
  • Open-Meteo：天気の予報を得るため、店の緯度・経度を送ります。個人の情報は送りません。
  • jsDelivr と cdnjs：アプリの部品とアイコンをここから読み込みます。これらのサービスには、IP アドレスなど通常の通信の情報が届きます。
  • ブラウザーの通知のサービス（例：Apple、Google）：通知をオンにしたとき、通知を届けます。

これらのサービスは、Funergy+ と当社の業務を動かすためだけに使います。提供先には、このポリシーと同等の保護を求めます。

個人の情報は販売しません。法令に基づくとき、または同意があるときにだけ開示します。上に書いた提供先以外には渡しません。

6. 保存する期間

情報は、Funergy+ と当社の業務に必要なあいだ保存します。業務・雇用・給与・税・会計の記録は 5 年保存します。

アカウントを止めることと、データを消すことは別の手続きです。退職したときやアカウントを止めたときは、PIN が使えなくなり、結びついたメールのログインも止まります。それまでに保存した記録は残ります。

これらは決まった時刻の処理ではありません。関係する操作があったときに消します。新しい変更の記録を書くとき、約 1 年より前の記録を消します。チャットを使っているあいだ、送らなかった添付は約 1 日後に消します。ログインの一時的な確認コードは数分で期限が切れ、残ったものは約 1 日後に消します。

ログインの記録、スタッフの情報（退職した人を含む）、応募者の情報（採用しなかった人を含む）、新しく入る人の本人確認書類の画像には、決まった保存期間を設けていません。このポリシーに書いた目的に必要なあいだ、または法令が求めるあいだ、保存します。

7. ご本人ができること・ご依頼

  • PIN はアプリで変えられます（マイページ › PIN設定）。
  • 通知はアプリでオン・オフできます。
  • ご自分の情報を見たい・直したい・消したいとき、または同意を取り消したいときは、office@funergygroup.com までご連絡ください。
  • 削除のご依頼があっても、残さなければならない記録があります。業務・雇用・給与・税・会計の記録は、5 年残します。

8. 安全のための取り組み

アプリのデータを見るにはログインが必要です。見られる範囲は役割で限り、アプリと当社のサーバーのあいだは暗号化した通信（HTTPS）でやりとりします。
